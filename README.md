The opencode counterpart of [kud/claude-plugins](https://github.com/kud/claude-plugins). Each plugin is a single file you drop in and name in your config: no package, no build step.

## Plugins

| Plugin                             | Kind | What it does                                                                         |
| ---------------------------------- | ---- | ------------------------------------------------------------------------------------ |
| [quiet-home](./plugins/quiet-home) | TUI  | The home screen laid out like a session: logo top left, prompt docked at the bottom. |

Each plugin's README covers installing it.
